§ 02 · 保险库PREMIUM

已加密，却依然只是文件夹。

保险库是磁盘上一组加密的文件 — 文件名、文件夹名和内容，全都在内。用密码打开它，树、预览、搜索和文件操作就和以往完全一样，作用在随取随解的内容上。关上它，磁盘上剩下的是读不懂的名字和没有意义的字节。

一个，或一千个

保险库就是对象

保险库和其他分支没有两样 — 一个磁盘上放一个，或放一百个，与普通文件夹并排。每个都有自己的密码。一个动作就能打开共用同一密码的全部，无论是一个还是一千个；一个动作也能把它们全部关上。

48 个单词

另一把钥匙，也是唯一的一把

每个保险库在创建时都会生成属于自己的 48 个单词 — 那就是它的密钥，以明文写出。密码，或者这些单词：没有别的东西能打开保险库。我们也打不开 — 两者都丢了，保险库就没了。请把这些单词放在保险库之外的地方。

一个盘符

对所有程序开放

给保险库一个盘符，它就成了这台机器上人人可用的普通磁盘 — ffmpeg、Word、WinRAR 以及资源管理器自己的录制器都能直接写入。挂载是用隐蔽换取兼容，所以它从来不是默认设置。

无需等待

在里面读与播放

文件是按块加密的，不是整体加密。4 GB 的视频不必先整个解密到内存 — 预览直接打开，还能跳到第四十分钟。文档、书籍和图片也一样，在保险库内预览。

保险库大小

与磁盘一样大

我们不设限制。一个保险库可以只装一个文件，也可以装下数千个文件、好几 TB。磁盘到哪里，它就到哪里。

文件大小

磁盘允许多少就多少

NTFS 上 16 TB，exFAT 上 16 EB — FAT32 上 4 GB，因为那是 FAT32 的限制，不是我们的。加密大约增加 0.09%，所以刚好装得下的文件会装不下：检查是按加密后的大小做的，会在开始前拒绝，并给出真实的数字。

不归我们扣留

Cryptomator 格式

格式是 Cryptomator 的，依据其公开规范重新实现，而且双向可用 — 已经验证。这里创建的保险库可以在 Android、iOS、Mac 和 Linux 上的 Cryptomator 中打开，无需转换。你已有的保险库在这里也能打开。就算 ExplorerFocus 明天消失，文件也不会。

能防住

  • 任何复制了该文件夹或磁盘的人 — 云同步、丢失的 U 盘、落在别人手里的备份
  • 在电脑关机时把它偷走的人
  • 能读取磁盘、但没有密码的人

防不住

  • 保险库开着时以你的身份运行的恶意软件 — 它和其他程序一样能读到解密后的文件
  • 键盘记录器，或在保险库开着时坐到你未锁定电脑前的人
  • 文件放进去之前就已经存在的明文副本
  • 在保险库关闭时向磁盘写入的人：他改不了你的内容 — 认证会发现 — 但他可以删除文件

为什么会有第二栏：把安全性说得比实际更高，是这类功能最糟糕的做法。这个门类里的每个产品都能公布这样一份清单，几乎没有谁公布。

一个值得知道的副作用：每个加密文件夹在磁盘上都处于同样很浅的层级，所以嵌套二十层的文件夹依然只是四段路径。Windows 资源管理器打不开的路径，在保险库里可以用。

PREMIUM — 创建保险库。打开保险库是免费的，包括在别处创建的。

§ 04 · 技术栈

由严肃组件构建。

每个依赖都因成熟度、体积,或缺少合理替代品而被选择。不追潮流框架。

完整清单随程序一起提供，包含每一位作者与完整的许可证文本 — 见「关于 → 第三方许可证」。

.NET

net10.0-windows

经典 WPF,不使用 WinUI 或 MAUI。兼容 Windows 10 与 11。

MVVM

CommunityToolkit.Mvvm

ObservableObject、ObservableProperty、RelayCommand — 由 source generators 生成。

加密

Bouncy Castle

scrypt、AES-SIV 与 AES Key Wrap，来自 Bouncy Castle（MIT）— 公开，且已被广泛使用二十多年。

盘符

Dokany · DokanNet

Dokany（LGPL v3）不随程序分发：由你自己安装，资源管理器只有找到它才会使用。而 .NET 桥接 DokanNet（MIT）确实随可执行文件一起发布。

格式

Cryptomator v8 · BIP-39

保险库格式采用 Cryptomator 的格式，依据其公开规范重新实现。恢复密钥使用 BIP-39 单词表（MIT）。

预览

AvalonEdit · Markdig · WebView2

语法高亮、Markdown 渲染、嵌入 Edge 引擎用于 PDF。

UTIL

Microsoft.VisualBasic.FileIO

用于送至回收站 — 唯一诚实且可行的方式。

远程

SSH.NET · FluentFTP

SFTP 通过 SSH.NET；FTP 和 FTPS 通过 FluentFTP。成熟，而且是那种好的无趣。

无 SDK

HttpClient

WebDAV、Dropbox 和 OneDrive 都是直接对着它们的 HTTP API 手写的。没有会过时的厂商 SDK。

采集

NAudio · NTwain

麦克风与系统声音通过 NAudio 和 WASAPI；扫描仪通过 NTwain，即 TWAIN 标准。

压缩包

SharpCompress

ZIP、RAR、7z 和 TAR 就地读取，压缩包像文件夹一样打开。

Windows 弹出警告？先看看你用的是哪个版本。

自 1.2.23 版（2026年8月18日）起，ExplorerFocus 已经过数字签名。由于签名是新的，Windows 打开时可能仍会要求确认：识别一个新的发布者需要一段时间，这不是文件的问题。而 1.2.23 之前的副本没有签名，有可能打不开 — 这种情况下不要等自动更新，更新功能就在程序里面，程序不启动它也不会运行。请在本页重新下载一次。

仅当你想完全确认下载的是未经改动的官方文件时。二选一即可。

首先，找到文件：打开 Windows 文件资源管理器（任务栏上的黄色文件夹，或按 ⊞ Win + E），点击左侧的下载——ExplorerFocus.exe 下载后就在那里。这要在文件资源管理器里做，不是在浏览器里。

SHA-256 是什么？

把它想成文件的指纹。一种算法读取 ExplorerFocus.exe 的每一个字节，把它们浓缩成一个 64 个字符的代码（字母 A–F 和数字）。这个代码就是 SHA-256。

它有两个有用的特性：

  • 同一个文件永远得到相同的代码。
  • 只要一个比特发生变化——下载损坏，或有人篡改了文件——代码就会完全不同。

所以验证很简单：如果你在自己文件上计算出的代码与这里公布的一致，就能确定它正是官方文件，逐字节相同——没有损坏，也没有改动。代码无法逆推：它只用于比较，绝不会泄露文件内容。
